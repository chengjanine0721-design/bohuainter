Ten modes cover almost every case fix you will run into, from shouting spreadsheet exports to clean code variable names. Each one runs the moment you click it, on whatever text is in the box above.

How to Use the Case Converter

Three steps, and no account anywhere in the flow.

  1. Paste or type your text into the box at the top of this page. The Sample button loads a test line if you want to see the modes in action first.
  2. Click the mode you need. The result panel updates on every keystroke as well, so you can switch between modes without retyping anything.
  3. Press Copy result and paste it where it belongs. Clear empties both boxes when you are finished.

The same single click handles a headline or a full chapter, because the conversion runs locally in your browser rather than through a queue on a server.

Why Use Bohuainter Case Converter: No Signup, Unlimited Use

No account, no email address, no daily quota and no watermark on the output. The converter is a short script that runs inside the tab, so the text you paste never travels to a server and nothing is stored once the page is closed.

Having ten modes in one panel also means less hopping between tools. A headline fix, a URL slug and a variable rename take place in the same box, with the same Copy button.

Why We Created This Tool: Built for 3 Common Use Cases

Case errors show up in predictable places. These are the three that prompted this tool.

  • Text that arrives in the wrong case. Spreadsheet exports that shout in caps, copy pasted out of a design file, OCR output from a scanned page and captions typed with caps lock on. Retyping is the slow fix and the one that adds new typos.
  • Headlines, titles and metadata. Title case for headings, sentence case for body copy, and URL Slug when the same headline has to become a clean permalink.
  • Code and developer handoff. Camel Case and Pascal Case keep variables, components and file names consistent without a manual pass through every line.
Questions

Upper Case Generator FAQ

Does the conversion keep my paragraphs?

Yes. Line breaks, spaces and punctuation are preserved exactly. Only the case of the letters changes.

Is there a length limit?

No limit is enforced. The text is processed in your browser, so a few hundred thousand characters will still convert instantly.

Which should I use for headings?

Title case is the common convention for headings and buttons on the web. Sentence case is the convention in many style guides for article titles and body copy.
