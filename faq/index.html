★ FAQ

Frequently asked questions

How the tools count, what happens to your text and which tool fits which job.

About the site

What is Bohuainter

A collection of free browser based tools that count characters and words, convert text case and check length limits for search results and social posts. Everything runs locally in your browser.

Is it really free

Yes. No account, no trial, no character cap. The site is funded by unobtrusive advertising, and no tool requires payment.

Do I need to create an account

No. There is no sign up anywhere on the site and no feature that requires one.

Does the site work on a phone

Yes. Every tool is responsive and the counters work the same way on mobile browsers. Typing long documents on a phone is awkward, but pasting and checking works well.

Privacy and data

Is my text uploaded to a server

No. The counting code runs in your own browser tab. You can disconnect from the internet after the page loads and the counters keep working, which is the simplest proof that nothing is sent.

Do you store my draft

No. There is no local storage, no session storage and no autosave. Reloading the page discards everything you typed.

Do you use cookies

The tools themselves set no cookies. Advertising partners may set measurement cookies, and where required a consent banner appears first.

Can I check whether it works offline

Yes. Load a tool page, then switch off your network connection. The counter keeps updating on every keystroke, because no request is involved.

Counting accuracy

How do you count words

Text is split on runs of whitespace, which is the same rule Microsoft Word and Google Docs use. Hyphenated compounds count as one word.

Why does your count differ from another tool

Different tools make different assumptions about hyphenated words, footnotes, numbers and CJK text. Where a limit will be enforced, check with the system that enforces it.

Do you count punctuation as characters

Yes. Characters include every character in the string, including spaces, punctuation and line breaks, which matches how most form fields measure length.

How is reading time calculated

At 225 words per minute, close to the average for adult silent reading of general prose. It is a planning estimate rather than a precise measure.

Tools

Which tool should I use for an essay

Start with the essay word counter, which tracks your draft against a target and shows pages and average sentence length at the same time.

Which tool converts words to pages

The words to pages calculator. It handles single and double spacing, US Letter and A4, and works in either direction.

Can I convert text to all caps

Yes, with the upper case generator. It also handles Title Case and Sentence case, and you can copy the result in one click.

Does the Twitter counter handle emoji

Yes. It applies the weighted counting X uses, where emoji and CJK characters count as two units and Latin letters as one.

Still stuck

Send us the tool name and what you expected to see. A short example is enough for us to reproduce it.
