How to Check Word Count in Microsoft Word on Any Device

The status bar for a quick total, the Review tab for the full breakdown, and the selection trick for one section, on Windows, Mac, mobile, and the web.

This guide explains how to check word count in Microsoft Word on Windows, Mac, mobile, and the web.

Finding Word Count in Microsoft Word on Windows

Word for Windows offers three ways to check document length: the status bar for a quick total, the Word Count window for detailed statistics, and selected text for checking a specific section. Each method serves a different counting need.

Check Word Count in the Status Bar

The status bar is the quickest way to count words in Microsoft Word while editing. Its total updates as the document changes, making it useful for checking progress against a word limit.

Step 1. Open your document in Microsoft Word.

Step 2. Look at the bottom-left corner of the window for the word count.

Step 3. If the count is missing, right-click the status bar and select Word Count to display it.

Clicking the displayed number also opens the detailed statistics window.

Use the Review Tab and Word Count Shortcut

If you need to do a word count in Microsoft Word beyond the running total, the Word Count window provides a fuller breakdown. It lists pages, words, characters with and without spaces, paragraphs, and lines. The separate character figures are useful when a task sets a character limit or specifies whether spaces count.

Step 1. Open the Review tab in the top ribbon.

Step 2. Select Word Count in the Proofing section.

Step 3. Select Include text boxes, footnotes, and endnotes if these parts should be included in the count.

The Windows shortcut Ctrl + Shift + G opens the same window directly.

Count Words in Selected Text

A document may have a word limit for only one section, such as an introduction or conclusion. In this case, a selected text word count is more useful than the document total because it shows the length of the specific passage being checked.

Step 1. Highlight the paragraph or section you want to count.

Step 2. Check the status bar for the selected word count alongside the full document total.

Step 3. Click the displayed word count to open the detailed statistics for the selected text.

Mac and Mobile: Where to Find Word Count

Word also supports word counting on Mac, iPhone, iPad, and Android. However, the menu layout differs between desktop and mobile versions, so the steps are not the same as on Windows.

Mac: Use the Status Bar or Tools Menu

Word for Mac shows the document total in the status bar. Clicking the count opens a detailed report, including a character count in Microsoft Word with and without spaces. The Tools menu also offers a separate way to count selected text.

Step 1. Open your document and check the word count at the bottom of the window.

Step 2. Click the displayed number to view detailed statistics, or open the Tools menu and select Word Count.

Step 3. To count a specific passage, select the text first, then open Tools and choose Word Count.

Mac users working in Apple Pages instead of Word need a different method. The guide to finding word count in Pages explains where to find that option.

iPhone: Locate Word Count in Review

On iPhone, Word Count is located in the Review tab inside the editing ribbon. The ribbon may be hidden when a document is first opened, which means the editing controls need to be expanded before the counting option appears.

Step 1. Open your document and tap the Edit icon to enter editing mode.

Step 2. Tap Home in the toolbar and select Review from the menu.

Step 3. Tap Word Count to view the document's word and character totals.

iPad: Access Word Count from the Ribbon

Word for iPad uses a wider ribbon layout, with the Review tab available at the top of the document. Unlike the phone interface, the tab does not need to be accessed through the collapsed Home menu. A selected passage can also be counted separately.

Step 1. Open your document in Microsoft Word.

Step 2. Tap the Review tab in the top ribbon.

Step 3. Select Word Count to view the document statistics.

Android: Open Word Count in the Review Menu

On Android phones, the Word Count option is also under Review, but the tab may be inside the expanded editing menu. The mobile layout differs from the iPad ribbon, even though both versions use the same counting feature.

Step 1. Open your document and tap the Edit icon.

Step 2. Tap Home in the toolbar and select Review.

Step 3. Tap Word Count to see the document's word and character totals.

Viewing Word Count in Word Online

Word for the web is useful when you edit documents in a browser or do not have the desktop app. Its built-in counter shows the document's length without downloading the file. The count appears in the status bar in Editing view, and if it is hidden, the Show Word Count setting may be off.

Step 1. Open your document in Word for the web. If it opens in Reading view, select Edit Document, then choose Edit.

Step 2. Check the bottom left corner of the window for the current word count.

Step 3. If the count is not visible, open the Review tab, select Word Count, then select Show Word Count.

This method works when the text is already in a Word document. If you only need to count copied text, an independent online counter offers another option without opening Word.

Frequently Asked Questions

Why Is Word Count Not Showing in Microsoft Word?

If the word count disappears from Word's status bar, the Word Count option may be turned off. On Windows, the display can be restored through the status bar menu by selecting Word Count. In Word for the web, the document must be in Editing view, with Show Word Count enabled under Review.

Does Microsoft Word Count Hyphenated Words as One?

Yes. Microsoft Word counts a standard hyphenated compound, such as long-term, as one word when no spaces appear around the hyphen. If the terms are separated by a space, as in long term, Word counts them as two words.

Does Microsoft Word Character Count Include Spaces?

Microsoft Word provides both options. The Word Count window lists Characters (with spaces) and Characters (no spaces) separately. The first includes spaces between words, while the second excludes them. The correct figure depends on the character limit specified by the assignment or document requirements.

Does Microsoft Word Count a URL as One Word?

Yes. A URL entered as one continuous string counts as one word, even when it contains periods, slashes, or other punctuation. If spaces divide the address into separate parts, Word counts those parts separately.
